# 💫 About Me:
Full Stack Web Developer specializing in Java and Spring Boot for backend development, with some experience in React on the frontend. I build scalable, secure, and maintainable applications following clean architecture principles and best practices.<br><br>I have experience working with microservices-based architectures using Spring Boot and Docker, and have implemented distributed systems components such as Spring Cloud Gateway, Kafka, gRPC, and Protocol Buffers.
